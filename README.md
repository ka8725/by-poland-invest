# XTB для белорусов в Польше

Готовая самостоятельная страница: `index.html`. Открывается прямо в браузере, не требует сборки, внешних шрифтов, библиотек или сервера. Пока не опубликована, по запросу автора интернет-публикация будет позже.

Реферальная ссылка: замените пустую строку в `const REFERRAL_URL = '';` в конце HTML на предоставленный HTTPS-адрес. Сейчас внизу страницы размещена обычная ссылка на официальный сайт XTB; после замены она будет вести по реферальному адресу.

Проверка сведений: 8 октября 2026 года. Перед публичным размещением перепроверьте доступность XTB для конкретного паспорта/ВНЖ, тарифы, налоговые правила и статус OKI. В статье приведены ссылки на источники. Безусловное утверждение «самый простой для всех белорусов» заменено обоснованной оценкой «один из самых простых» для проживающих в Польше; одобрение счёта не гарантировано. OKI вступает в силу 1 января 2027 года, его запуск в XTB не заявлен как свершившийся факт.

Для публикации достаточно загрузить `index.html` на статический хостинг. Для локального просмотра через HTTP можно выполнить `python3 -m http.server 8000` в этой папке.

## Версия для новичка

Материал выстроен от объяснения акций, ETF и брокера до открытия счёта, расходов, выбора налогового счёта и защиты активов. Подробности налоговых программ раскрываются отдельно.


## ETF и доходность

Раздел о брокере дополнен объяснением широких индексных и аккумулирующих ETF, расходов фондов и польского налога на дивиденды. Примеры: Vanguard All-World (EUR), iShares ACWI (USD), PZU MSCI World с хеджированием в PLN. PZU покрывает только развитые рынки и имеет короткую историю; примеры не являются рейтингом.

Таблица на 30 сентября 2026 года показывает все десять запрошенных периодов и переключается между суммарной и среднегодовой доходностью. Недостающая история явно отмечена. Данные, месячные результаты Vanguard, валютные курсы NBP, формула пересчёта и ссылки сохранены в `research/etf-performance-2026-09-30.json`. EUR-результаты Vanguard рассчитаны из стоимости доли в USD, а не из биржевых цен Xetra. Историческая доходность включает расходы фонда, но не индивидуальные налоги и расходы брокера.

Проверены мобильная ширина 320/390 px, десктоп, раскрытие таблицы, оба режима доходности, калькулятор IKZE и отсутствие ошибок JavaScript.
